# AI Development Portfolio

## 自己紹介・概要

生成AIを活用したソフトウェア開発に取り組んでいます。

ChatGPTやGitHub Copilotを利用し、AIによるコード生成や修正、設計の相談などを行いながら開発しています。

このページでは、AIを活用して制作したツールと、その開発過程を紹介します。

## 使用AI

- ChatGPT：設計相談、コード生成、改善案の検討
- GitHub Copilot：コード生成、補完、実装支援

## 開発実績

### 1. Quick Actions
VS Code初心者向けの開発支援拡張機能。

### 2. Unity Assist Tools
Unityでの開発作業を支援するツール群。

## 開発で意識していること

- AIに任せきりにせず、生成された内容を確認する
- 必要な機能や改善内容を自分で考える
- 問題点を見つけ、改善を繰り返す
- 利用者にとって使いやすいツールを目指す
